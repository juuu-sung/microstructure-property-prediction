# 검증 설계와 해석 범위

## 단위와 분할

- 정답 단위는 이미지 1장이다. 8개 D4 view와 국소 patch는 같은 이미지의 표현이며 서로 다른 검증 fold에 나누지 않는다.
- 주된 비교: seed42 / seed2026, 5 outer fold(학습400 / 검증100), 3 inner fold.
- 추가 확인 seed31415 / 27182 / 16180도 같은 500장의 재분할이다. 독립 확인 데이터가 아니다.
- 보고 수치는 각 seed의 전체 OOF RMSE이다. fold RMSE의 단순평균이나 여러 seed 예측 평균으로 바꾸지 않는다.

## 학습 경계

StandardScaler, PCA, GMM, 회귀기와 checkpoint/alpha 선택은 해당 학습 문맥의 자료만 사용한다. outer 정답은 최종 진단에만 사용한다. 혼합 평가에 쓰는 내부 기준 예측도 같은 inner 문맥에서 생성하며, 전체 OOF나 전체500 학습 예측으로 대체하지 않는다.

최종 제출은 전체500에서 내부 검증으로 alpha를 선택한 후 다시 적합한다. 이 선택 점수는 성능 추정치가 아니다. 테스트 영상은 최종 특징 추출·추론에만 사용하고 표준화·규제값·혼합비 학습에 사용하지 않는다.

## 기존 모델과 Fisher의 선택 목적 구분

최고 제출 구성은 S50% + L25% + C25%이다. 당시 C-RADIO의 alpha는 보존된 내부 대조 목적(.5S + .5C)으로 선택했다. Fisher 실험에서는 다음을 분리했다.

| 구분 | 표현 | alpha 선택 목적 |
|---|---|---|
| A | 보존된 전역 C-RADIO | 기존 선택 규칙 유지 |
| B | 같은 전역 C-RADIO | 실제 .5S + .25L + .25C 내부 MSE |
| C | 전역 + Fisher | B와 동일 |

B/C의 내부 Large 예측은 inner 학습 문맥 안에서 추가 CV로 alpha를 정했다. Fisher의 PCA32·GMM8도 각 inner 문맥과 outer 재학습 문맥에서 별도로 적합해 총40개 사전을 만들었다. 이 비교는 선택 방식의 변경만으로 발생한 개선을 새 특징의 효과로 오인하지 않게 한다.

## 오류 구간

공통16은 이전 실험들의 큰 오차로 선택한 **사후 진단 집합**이다. 무작위 또는 독립 검증 집합이 아니다. 나머지484, 정답 상·하위10%, 중간80%, 영상 잡음 사분위, fold, 새 worst20을 함께 살핀다. 정답 구간과 공통16을 test 모델 라우팅에 사용하지 않는다.

## 남는 한계

중첩 검증은 한 번의 실험 내부에서 누출을 줄이지만, 같은500장을 수십 차례 검토하며 다음 가설을 고른 연구 과정 전체의 선택 편향을 없애지는 않는다. 독립 표본처럼 seed 차이를 취급하거나 통계적 유의성을 주장하지 않는다. 평균 개선 .30 등 투자 기준은 통계적 유의성 임계값이 아니었다.
