# 종료 회고

## 유지할 점

대조군을 함께 두고 전체 오차와 실패 구간을 모두 확인했다. 고정 특징은 인코더 추론과 회귀 학습을 분리해 재사용했다. source/input/environment 해시와 완료 manifest로 중단 재개 시 잘못된 결과 혼합을 방지했다. 기대와 다른 결과도 남기고 최종 제출에는 채택 근거가 있는 구성만 포함했다.

## 바꿀 점

후반에는 같은 표현의 회귀기·규제·작은 혼합 개선을 추적하는 실험이 많았다. 같은500장에 반복적으로 의존해 선택 편향이 커졌고, 작은 이득의 의미를 과도하게 검토하는 데 시간이 들었다. 해시로 결합된 장기 파이프라인은 무결성에는 강했지만 독립 실행과 외부 재현을 어렵게 했다.

다음 프로젝트에서는 연구 시작 시 예산·중단 기준·최소 기대효과를 명시하고, 재사용 가능한 특징 인터페이스와 독립된 실험 설정을 먼저 정리한다. 가능한 경우 가설 개발에 쓰지 않는 별도 홀드아웃을 확보한다. 독립 데이터가 없다면 결과 주장도 그에 맞게 제한한다.

## 목표 달성 여부

최초 제출 대비 Public RMSE 약6.7% 개선은 얻었지만, 목표했던10 미만·상위권 성능은 달성하지 못했다. 12점이 데이터의 성능 한계라는 증거도 없다. 공통16의 원인이 라벨 오류·비가시적 생성 변수·표현 부족 중 무엇인지 확정하지 못했다.
